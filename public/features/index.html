One workspace for the shop day

Run the counter, the bays, and the books together.

MechPro is the operating system for an auto repair shop: who is in which bay, what was promised, what the customer approved, and what still needs to be collected.

Start a shop Open the app

Today

Home opens on what needs a decision: unassigned jobs, parts holds, overdue invoices, and the work promised for today.

Dispatch

Move estimates, approved work, jobs in progress, and parts holds across the board. Assign a technician and a promise time in the same place.

Front counter

Work orders, customers, vehicles, and invoices stay linked. Search by RO, name, or VIN without leaving the shop.

Shop floor

Inspections, inventory, canned services, reminders, and basic OBD-II live beside the repair order. OEM diagnostics stays on licensed Windows hardware.

AI workbench

Symptom notes, estimates, and technician worksheets are advisory. Technicians still confirm specs, torque, and authorization before parts are sold.

Back office

Employees, time clock, payroll stubs, accounting, reports, and imports. Payroll tax figures are a small-shop estimate, not a payroll-processor filing.

Same shop on every screen. Use the browser, install the Windows app for bay computers, or install the Android package for the floor. Sign-in is a one-time link to a work email. MechPro does not store shop passwords.
